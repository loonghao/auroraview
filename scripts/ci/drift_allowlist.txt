# Test suites deliberately excluded from the CI run set.
#
# Consumed by scripts/ci/check_test_drift.py, which fails CI when a test file
# is collected by pytest but never executed by any workflow.
#
# Rules:
#   * One path per line. `#` starts a comment.
#   * EVERY entry must justify itself: inline `# reason`, or a `#` comment on
#     the line directly above. An entry without a reason fails the check.
#   * Entries are only for suites that CANNOT run in CI. Merely inconvenient
#     suites belong in a CI job, not here.
#   * The check fails on stale entries (CI runs them again) and dangling
#     entries (path no longer exists). Delete those instead of editing them.
#
# Rationale for each entry is also documented in docs/testing/drift-allowlist.md
